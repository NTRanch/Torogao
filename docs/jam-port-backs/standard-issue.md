# Port-back — Standard Issue → torogao

What W14 validated, in torogao terms. (Content labels per §9: the

## Validated, ready to port

1. **Certification as a game loop** (SFW technique). Teach → arm →
   paper → book entry. The exam never feels like a menu because
   every stage is played: the basics are taught in the open, the
   plug's phrase is spoken, the paper is a performance, and the pass
   is a ceremony (entered aloud). Ports as the ACHIEVEMENT-SYSTEM's
   certification flow, unchanged in shape.
2. **The book of record implementation** (SFW technique). Two bits
   of state (Fit, Signals), written at the MOMENT of passing (a later
   failure in the same sitting does not unwrite them — proven by
   test), tier computed by the core from the bits, never stored as a
   number. The shell persists the bits; the arithmetic is law, not
   data. Ports directly as torogao's book-of-record seam.
3. **T-gate arithmetic at prototype scale** (SFW technique). T1 = any
   paper, T2 = Fit + Signals, T3 = two standards — displayed IN the
   book with the current state, including the honest "locked here"
   for a gate this game cannot satisfy. Gates that show their own
   arithmetic teach the system while they gate it.
4. **The education layer rule** (SFW technique). Safety basics are
   the first teach card of every paper, always shown, never gated,
   and the brief repeats them. "The test is the teach" ports as a
   content rule for any torogao exam or protocol introduction.
5. **Phrase sets per protocol level** (SFW technique). Each paper
   carries its own trigger phrase (MEASURE ME. / READ ME.), taught
   on its own card and required at its own plug. The by-heart
   finding holds at set scale: one phrase per level, no more.

## Verdict against Piper's ladder record

Standard Issue closes the program on Piper's protocol set from the
other side: not the orders she gives, but the standards she certifies.
The certification loop gives the ACHIEVEMENT-SYSTEM its missing
proof — a standard earned in play, recorded in a book the player can
re-read at the title screen, with the next gate's arithmetic already
showing.
