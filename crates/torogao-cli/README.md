# torogao

mcp-name: io.github.NTRanch/torogao

The Torogao command-line tools: the registry, MCP and A2A servers,
scenes, writer, tutorials, toolbox, and conversion.

This crate is the `torogao` binary package (from `crates/torogao-cli`
in the Torogao workspace). Run it with no arguments for the tool
surface, or in `mcp` mode for the MCP server.
