# Torogao

A character-animation editor from **Nice Thoughts Ranch**:
2D puppet rigs, governed expressions, scenes, and a playroom —
with a Persona-style stage for a user interface and a traditional
panel UI ("Nerd mode") one toggle away.

Torogao began as a downstream fork of the Inochi Creator /
inochi2d codebase (BSD-2-Clause) written in D. It is being ported
to **100% Rust**; the D build, complete and gated through phase
P5b, is frozen as the reference implementation for the port.

- The port plan: [PORT-PLAN.md](PORT-PLAN.md)
- Status: port phase RP0 (workspace + gate wiring) is in progress.
